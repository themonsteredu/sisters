# Sisters 홍보영상

- `sisters-promo.mp4` — 1920×1080, 30fps, 약 55초, 배경음악 + 하단 한국어 자막 포함
- 실제 앱 화면(데모 모드)을 녹화해 편집했습니다: 한 줄로 학습계획 만들기 → 학생의 타이머·사진·메모 제출 → AI 1차 분석과 부모 검수 → 영단어 테스트 → 대시보드·자녀별 리포트
- 화면 속 이름·과제·점수·노트 사진은 모두 데모용 가상 데이터입니다. 실제 개인정보는 들어가 있지 않습니다.
- `sisters-promo.srt` — 자막 파일 (유튜브 등에 따로 올릴 때 사용)
- `source/` — 다시 만들 때 쓰는 녹화·편집 스크립트 (앱 배포에는 포함되지 않음)
  - `rec.mjs`, `go.mjs` — 데모 모드로 켠 앱(`npm run dev`)을 Playwright로 녹화
  - `note.html`, `note.mjs` — 학생 제출용 가상 노트 사진 만들기
  - `compose.html`, `render.mjs` — 장면·자막·진행바 편집 화면을 프레임 단위로 렌더
  - `music.py` — 직접 합성한 배경음악 (저작권 걱정 없음)
